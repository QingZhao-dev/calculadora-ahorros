
# Calculadora de ahorros

## Descripción
Aplicación web que permite calcular el progreso hacia un objetivo de ahorro y conocer cuánto dinero falta para alcanzarlo.

## Funcionalidades
- Introducir un objetivo de ahorro.
- Consultar el progreso hacia el objetivo.
- Calcular la cantidad que falta para alcanzarlo.

## Tecnologías utilizadas
- **HTML5:** estructura de la página y campos de entrada.
- **CSS3:** diseño y presentación de la interfaz.
- **JavaScript:** cálculos y actualización de los resultados.

## Posibles mejoras
- Gestionar varios objetivos de ahorro.
- Registrar la evolución del ahorro.
- Estimar cuánto tiempo se tardaría en alcanzar un objetivo.
